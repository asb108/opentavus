# Locally served font notices

The build copies these notices beside Excalidraw's self-hosted font files. The metadata was retained from Excalidraw v0.18.0 font source comments (commit `817d8c553c3389650f8b4503984a6d4a5d2f0c11`) and from the actual installed font name tables. Additional source license texts identify their URLs in each file. Excalidraw's resolved package version is recorded in `package-lock.json`; update this review when font artifacts change.

Comic Shanns uses MIT terms; Excalifont, Virgil, Assistant, Cascadia, Liberation, Lilita One, Nunito, and Xiaolai use their retained SIL Open Font License terms. Figtree and KaTeX notices are copied from their installed packages during the build. Font licenses remain separate from the application's Apache-2.0 source license.
