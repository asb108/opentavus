# Project decisions

[Atul Bisht / asb108](https://github.com/asb108) maintains this independent project.
Contributors can propose work through issues and pull requests. Contributors do not
need access to an inference service or GPU for the base checks.

Small fixes follow the existing design and can go directly to a focused pull request.
For a new engine, public contract, default behavior, saved format, or large dependency,
open an issue with the problem, proposed user behavior, alternatives, licensing and
verification. A short recorded decision is sufficient; there is no committee process.

Maintainers review compatibility, user value, complexity, licenses and evidence. A
popular proposal can remain experimental when it has not been tested on the claimed
hardware. Accepted substantial decisions are recorded in [docs/decisions.md](docs/decisions.md).

Contributions are licensed under the repository's Apache-2.0 license. Preserve
third-party notices and supply the actual terms for models and assets. No separate
contributor license agreement is currently required. A sign-off is welcome but
is not a merge requirement. Only submit work you have permission to contribute.

Credit contributions in pull requests and release notes. A coding agent's human
operator is responsible for checking the resulting contribution and its claims.
